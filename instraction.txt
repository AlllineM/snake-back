Основное:
- В /etc/ssl/ создать aliker.ru.crt.
- Засунуть в этот один файл последовательно содержимое из certificate.crt, inter.crt и root.crt. (сертификат, промежуточный серт и корневой серт)
Нужны в итоге файл aliker.ru.crt и aliker.ru.key - ключ кажется тоже летит на почту.

Закинуть подготовленные файлы на сервак:

5.2) Поставить ssl, если самоподписанный, с помощью letsencrypt и curtbot.
В этом случаее это надо делать после шага 6))
- На серваке установить curtBot:
sudo apt install certbot python3-certbot-nginx
- В домене должна быть прописана А-запись с айпишником сервака(привязка с серваку)
- Нжинкс нужен уже в настроенном состоянии, и конфиге должен быть прописан
server_name aliker.ru;
- Если все это есть, то после установки сертбота, генерим сертификат через плагин для нжинкса:
sudo certbot --nginx -d aliker.ru -d www.aliker.ru
-Он спросит, выставлять ли перенаправление. Выставлять. (сейчас нет ничего на http)
Если все ок, он сам генерит сертификаты и прописывает их в логах нжинкса,
    меняя ssl_certificate и ssl_certificate_key на новый путь к сертификатам

6) Создать виртуальных хост и проксю для ssl:
cd /etc/nginx/sites-available/
nano aliker.ru

конфиг:
server {
        listen 443 ssl;
        server_name aliker.ru;
        ssl_certificate /etc/ssl/aliker.ru.crt;
        ssl_certificate_key /etc/ssl/aliker.ru.key;

        root /var/www/html;

        location / {
            proxy_pass "http://localhost:8000";
        }

        location /api {
            proxy_pass "http://localhost:7777";
        }
}

Создать симлинк:
cd /etc/nginx/sites-enabled/
ln -s /etc/nginx/sites-available/aliker.ru /etc/nginx/sites-enabled/aliker.ru

Конфиг нжинкса:
server {
        listen 443 ssl;
        server_name aliker.ru;
        ssl_certificate /etc/ssl/aliker.ru.crt;
        ssl_certificate_key /etc/ssl/aliker.ru.key;

        root /var/www/html;

        location / {
            proxy_pass "http://localhost:8000";
        }

        location /api {
            proxy_pass "http://localhost:7777";
        }
}
server {
    listen 7777;
    index index.php index.html;
    error_log "/var/log/nginx/error.log" debug;
    access_log /var/log/nginx/access.log;
    root /var/www/back-aliker/public;

    location / {
        try_files $uri $uri/ /index.php?$args;
    }

    location ~ \.php$ {
        try_files $uri = 404;
        fastcgi_split_path_info ^(.+\.php)(/.+)$;
        fastcgi_pass unix:/var/run/php/php7.4-fpm.sock; # подключаем сокет php-fpm
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}

If you want to run docker as non-root user then you need to add it to the docker group.

    Create the docker group if it does not exist

$ sudo groupadd docker

    Add your user to the docker group.

$ sudo usermod -aG docker $USER

    Log in to the new docker group (to avoid having to log out / log in again; but if not enough, try to reboot):

$ newgrp docker

    Check if docker can be run without root

$ docker run hello-world

Reboot if still got error

$ reboot
