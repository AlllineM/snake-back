Доступ к вдс: 
- просто ssh ключ добавить в интерфейсе хостинга.
- пароль есть на почте, при регистрации шлют

Привязать домен: 
зайти туда, где куплен домен. Ресурсная запись А — тупо прописать айпишник сервера. 

Разворачивание: 

- Добавить ssh сервака в гит. Склонить проекты, фронт и бек.

- Фронт:
 
1) В корне проекта:

docker build -t front .      Если  падает на npm install, можно тупо запустить еще раз, 					     может падать из-за памяти

2) docker run -p 8000:8080 -d --name aliker-front front        Запускает контейнер на 8000 порту

- Бэк:

1) Создать .env файл. Скопировать туда образец из env_example

2) В папке docker:

docker-compose up -d      Если падает, тупо перезапускать. Падает из-за коннекта или                     		                  по памяти. Вообще сыпет дофига ошибок, но если в итоге 				      запускается, то это норм)
	
3) Накатить компосером библиотеки:

docker exec -it php-fpm sh     Зайти в контейнер с пыхой
composer install
