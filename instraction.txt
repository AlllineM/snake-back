Привязать домен:

Разворачивание:

- Добавить ssh сервака в гит. Склонить проекты, фронт и бек.

- Фронт:

1) В корне проекта:

docker build -t front .
Если  падает на npm install, можно тупо запустить еще раз,
может падать из-за памяти

2) docker run -p 8000:8080 -d --name aliker-front front
Запускает контейнер на 8000 порту

- Бэк:

1) Создать .env файл. Скопировать туда образец из env_example

2) В папке docker:

docker-compose up -d      Если падает, тупо перезапускать. Падает из-за коннекта или
по памяти. Вообще сыпет дофига ошибок, но если в итоге
запускается, то это норм)

3) Накатить компосером библиотеки:

docker exec -it php-fpm sh     Зайти в контейнер с пыхой
composer install

4) Накатить дамп базы:

Скопировать ранее сделанный дамп на сервак
scp /home/alina/projects/aliker/backups/aliker_28.03.2023.dump  root@188.225.77.125:/var/aliker_backups

Накатить в докер-контейнер
cat aliker_28.03.2023.dump | docker exec -i postgresql psql -U aliker -d aliker
